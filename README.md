# Morimoto E Garcia

Bem-vindo ao repositório oficial do site/projeto **Morimoto E Garcia**. Este é um projeto web desenvolvido para apresentar os serviços de advocacia e consultoria da firma Morimoto & Garcia, com foco em direito empresarial, tributário e internacional. O site é responsivo, moderno e otimizado para SEO.

## Funcionalidades Principais

- **Página Inicial**: Apresentação da firma, missão e visão.
- **Serviços**: Detalhes sobre áreas de atuação (ex. Direito Empresarial, Tributário, etc.).
- **Equipe**: Perfis dos sócios e advogados.
- **Contato**: Formulário de contato integrado com e-mail.
- **Blog/Artigos**: Seção para publicações e notícias.
- **Responsividade**: Adaptável a dispositivos móveis, tablets e desktops.

## Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3 (Tailwind CSS para layout responsivo), JavaScript (com bibliotecas como jQuery).
- **Backend**: [Node.js com Express].
- **Banco de Dados**: [Ex. MySQL ou Firebase, se houver funcionalidades dinâmicas].
- **Outros**: Git para versionamento, NPM para gerenciamento de pacotes.

## Pré-requisitos

Antes de rodar o projeto, certifique-se de ter instalado:
- Node.js (versão 14+)
- Git
- Um navegador moderno (Chrome, Firefox, etc.)

## Instalação

1. Clone o repositório:
   ```
   git clone https://github.com/TGuiDev/Morimoto-E-Garcia.git
   ```
   
2. Navegue para o diretório do projeto:
   ```
   cd Morimoto-E-Garcia
   ```

3. Instale as dependências (se houver um `package.json`):
   ```
   npm install
   ```

4. Configure variáveis de ambiente (se necessário, ex. chaves de API para formulários de contato). Crie um arquivo `.env` baseado no `.env.example`.

## Como Rodar

- **Modo Desenvolvimento**:
  ```
  npm run dev
  ```

  O site estará disponível em `http://localhost:3000` (ou porta configurada).

- **Modo Produção**:
  ```
  npm run build
  npm start
  ```

  
- Para deploy, use plataformas como Vercel, Netlify ou Heroku. [Ex. Instruções para Netlify: Conecte o repositório e configure o build command como `npm run build`].
